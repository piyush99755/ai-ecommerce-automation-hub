# Returns & Refunds Policy

Demo Store Return & Refund Procedures:
- 30-Day Money-Back Guarantee: Eligible items can be returned within 30 days of delivery in original condition and packaging.
- How to Initiate a Return: Contact support via email at support@example.com with your Order ID to request a return label.
- Refund Processing: Approved returns are refunded back to the original Stripe payment method within 5-7 business days after item inspection.
- Return Shipping Costs: Free return shipping for defective items. Standard return shipping fee applies for preference returns.
- Non-refundable Items: Digital downloads or gift cards are non-refundable.
- Automatic Mutations: Note that AI Support Assistant is read-only and cannot process refunds directly. Returns must be requested via support staff.
